# LeaderboardCore
A library for custom leaderboard to attach to Beat Saber. **Requires** Zenject on your mod for this to work. Please refer to the XML comments to see how to use the library.

## About this fork

This is a personal, unofficial fork of [rithik-b/LeaderboardCore](https://github.com/rithik-b/LeaderboardCore), porting it to Beat Saber 1.45.1 (a dependency of ScoreSaber's leaderboard UI, which isn't supported upstream yet). Distributed here under the same [GNU GPLv3 License](LICENSE) as upstream — all credit for the original library goes to its authors.
